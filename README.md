### 01 · Revenue & Retention Analytics

**Python · pandas · SQL · DuckDB · matplotlib**

- A reproducible analysis of **18,491 observed orders** and **4,337 identified customers**.
- Distinguishes revenue after the first order from all revenue generated by repeat buyers.
- Uses mature cohorts and explicit follow-up windows rather than treating censored observations as failures.

### 02 · ShopPulse — Modern Data Platform

**PostgreSQL · MinIO · dbt · Dagster · Metabase · GitHub Actions**

- Database, paginated API and CSV ingestion with deterministic raw versions and checkpoints.
- **18 dbt models**, customer SCD Type 2 history and **62 passing data tests**.
- Scheduled execution, retries, date-range backfills and deliberate failure demonstrations.
- Six Metabase questions and point-in-time customer features.

The first release is validated locally and on a fresh GitHub Actions runner.
This is a **local portfolio platform with synthetic data**, not a production deployment.
The source repository is currently private; access can be shared by invitation.

## Working approach

**Reproducibility → explicit assumptions → automated checks → documented results.**

Each project includes runnable instructions and explains its limitations.
Analytics results are descriptive; engineering demos show the actual scale and environment tested.
